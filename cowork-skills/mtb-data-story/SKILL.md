# MTB Quarterly Data Story

## Sourcing rule (non-negotiable)
Every number must trace to a published primary source: port authority annual reports, MedCruise/CLIA statistics, national statistics offices. The app's modeled figures (ship estimates, pressure scores) are NEVER used as evidence in the pitch — the app is the "explore it yourself" hook, not the data source. If a port's throughput can't be verified, exclude it and note the exclusion.

## Steps
1. Web-search latest published annual cruise passenger throughput for ~20 Med ports (Dubrovnik, Santorini/Thira, Kotor, Palma, Valletta, Barcelona, Marseille, Civitavecchia, Piraeus, Venice, Split, Corfu, Mykonos, Livorno, Naples, etc.). Record source + year for each.
2. Pull census population for each port town from national statistics offices. Record source.
3. Compute passengers-per-resident. Build the ranked table with a sources appendix (every row cited).
4. Produce: (a) 600-word analysis memo, (b) chart pack (2-3 charts), (c) 150-word pitch email, (d) target list of 25 journalists who have covered overtourism in the last 18 months — verify each byline exists, include outlet + recent relevant article URL.
5. Output to review queue. Greg reviews sourcing and sends pitches from his own email — never send anything.

## Voice
Conclusions first. Specific numbers. No adjectives doing the work numbers should do.
