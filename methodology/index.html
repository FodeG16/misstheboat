How the numbers work

Every figure on this site is a modeled seasonal estimate, not live vessel tracking. This page explains exactly what goes in, what comes out, and where the model can be wrong.

Inputs

  • Port-call patterns: curated seasonal day-of-week call intensity for 66 Mediterranean cruise ports, compiled from published cruise line itineraries and port schedules.
  • Excursion mapping: which destinations sit within typical shore-excursion range of each port, and which nearby places the excursion circuit skips.
  • City traffic patterns: baseline day-of-week visitor patterns per destination, independent of cruise traffic.
  • Population data: census figures used to compute passengers-per-resident pressure.
  • Weather: historical data from the Open-Meteo archive API (the one live data source).

The pressure index

For a given destination and date, the model combines estimated ship arrivals at nearby ports, excursion spillover, baseline city traffic for that weekday, and local population into a 0–100 pressure index. Verdicts: Avoid (high pressure), Caution, Clear.

What this is not

Ship counts shown as “≈5 ships” are seasonal-pattern estimates, not AIS tracking. A specific date can differ from the pattern — itineraries change, ships cancel, weather diverts. Treat verdicts as planning guidance, not measurements. Live vessel data is on the roadmap.

Corrections

Spot an error in a destination page? The dataset is actively maintained — use the contact link on the homepage.
